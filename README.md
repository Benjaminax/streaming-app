# Stillroom

A responsive streaming catalog prototype built with React, Vite, and Tailwind CSS.

## Features

- Search titles by name, genre, type, or year.
- Filter the catalog by genre and browse films or series.
- View title details and manage a personal watchlist.
- Resume items from the Continue Watching section.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check the source.

The catalog uses sample metadata and remote artwork. Streaming playback requires a connected video provider.
